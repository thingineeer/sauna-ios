# ① BRIEF (한 장 요약)

## 앱 정체성 (한 줄)
> **"말하고 3분 뒤 사라지는, 익명 실시간 수다 광장. 화면에 L/R 에어팟이 있고 메시지가 좌우로 왔다갔다 한다."**

## 한 문장 가치 제안
한국 직장인/학생이 **회원가입 없이 즉시 들어와서**, **일상·주식·취준** 중 하나를 골라 **자동 익명 닉네임**으로 떠들고, 메시지는 **3~10분 뒤 자동 증발**한다.

## 핵심 컨셉 5가지
1. **L/R 에어팟 UI** — 화면에 큰 에어팟 두 개. 메시지가 교대로 좌우에 뜸. 동시 메시지는 2개만 화면에 있음
2. **휘발** — 일상 3분, 주식·취준 10분 후 메시지 소멸
3. **익명** — 회원가입 X, 자동 닉네임 ("퇴근하고싶은판다#1203")
4. **3개 방, 전원 한 방** — 일상/주식/취준 각각 하나의 글로벌 방. 샤딩 X. 모든 사용자가 같은 방
5. **쉬운 스위칭** — 상단 탭 또는 좌우 스와이프로 방 전환

## 타겟
- 한국 20–35 직장인·취준생·대학생
- 한국 한정 서비스 (MVP)
- iOS 17+ 대상 (Android는 후속)

## 톤 & 무드
- **야무지고 즉시성 있는** 다크 모드 (검은 배경 + 네온 액센트)
- 귀엽거나 장난스럽지 않음. **젠지/밀레니얼의 미니멀 감성**
- Apple·Snapchat·Discord 사이 어딘가
- 글래스모피즘 + 네온 글로우 조합

## 레퍼런스
- **Apple AirPods 공식 렌더링** — 글래스 질감, 입체감
- **Snapchat 스토리 전환** — 휘발성 애니메이션
- **Discord 보이스 채널 활성화** — 발화자 하이라이트
- **Clubhouse 발언자 표시** — 원형 강조
- **Apple Wallet** — 다크 배경 카드 글로우
- **Linear 앱** — 미니멀 타이포 + 가독성

## 절대 피할 것
- 말풍선 채팅 리스트(카톡 스타일) — 우리 UI 본질과 충돌
- 프로필 사진 / 아바타

# ③ COMPONENT SPEC (반복되는 UI 요소)

## C1. **AirPod 말풍선 (핵심)**

화면의 주인공. 좌/우 두 개가 항상 존재.

### 상태
| 상태 | 설명 | 비주얼 |
|---|---|---|
| `idle` | 메시지 없음, 대기 중 | 반투명 글래스 원, 약한 호흡 scale 0.96↔1.0 (2초 주기) |
| `active` | 메시지 표시 중 | 방 accent 색 글로우, scale 1.0, shadow 30pt |
| `appearing` | 방금 새 메시지 들어옴 | 200ms: scale 0.95→1.03→1.0, opacity 0→1 |
| `disappearing` | 밀려나는 중 | 250ms: opacity 1→0, y -2pt, blur 0→4 |
| `reacting` | 사용자가 탭해서 리액션 | 하트 파티클 3–5개, 400ms |

### 구조
```
[원형 pod 배경 — 글래스모피즘]
  ├─ [중앙: 메시지 텍스트]  ← 최대 3줄, 200자
  ├─ [하단: 닉네임]          ← 모노스페이스, accent 색
  └─ [최하단: 수명 바]        ← 얇은 선, 시간 지나며 줄어듦
```

### 사이즈
- 지름: 화면 폭의 42%
- L과 R 사이 간격: 화면 폭의 8%
- 화면 세로 중 40% 영역 차지 (수직 중앙)

### 인터랙션
- **탭**: 해당 메시지 리액션 (하트)
- **길게누름(0.4s)**: 신고 시트 오픈 + 메시지 일시정지 5초

## C2. **방 탭바 (상단)**

3개 방 전환. 단순하지만 쉬운 접근성이 핵심.

### 구조
```
[일상]  [주식]  [취준]      1.2k ▼
  ↑ 선택됨 (accent 색 언더라인)
```

### 상태
- `unselected`: 회색 텍스트, 언더라인 없음
- `selected`: 흰색 + 방 accent 언더라인 2pt
- `switching`: 전환 애니메이션 중 (언더라인이 미끄러짐)

### 인터랙션
- **탭**: 즉시 해당 방 전환
- **좌우 스와이프 (화면 전체)**: 인접 방으로 이동 (iOS `PageView` 느낌)

### 접속자 수 칩 (우측)
- `1.2k ▼` — 탭하면 드롭다운으로 방별 실시간 인원 (`S13`)

## C3. **메시지 수명 바**

휘발 시각화.

### 구조
```
━━━━━━━━━━━━━━━━━━  ← 수명 100%: 꽉 참
━━━━━━━━━━           ← 50%: 절반
━━                   ← 10%: 거의 끝
```

### 속성
- 높이: 2pt
- 색: `rgba(255,255,255,0.3)` → accent 색으로 끝날수록 변화
- 마지막 20%: 살짝 깜빡임 (opacity 0.7↔1.0, 500ms 주기)

### 구조
```
┌──────────────────────────┐
│ 지금 뭐해?          [→]  │
└──────────────────────────┘
```

## C12. **음성/메시지 L↔R 이동 애니메이션 ⭐ (핵심 차별화)**

> 네 아이디어: **음성/메시지가 왼쪽 에어팟 → 오른쪽 에어팟으로 "이동"하는 느낌**.
> 이게 우리 앱 정체성의 시그니처 모션. 절대 대충 넘어가면 안 됨.

### 컨셉
- 에어팟 두 개 사이의 **가상 공간**에 메시지가 "떠다니는" 감각
- 카톡처럼 말풍선이 "뜨고 쌓이는" 게 아니라, **공기 중을 흐르는 소리 파동**처럼 표현
- 에어팟을 귀에 꽂으면 실제로 **L→R로 사운드가 이동** (시각과 스테레오 팬 일치)

### 비주얼 구성 (`A04: voice_wave_L_to_R`)

```
[L pod]                                         [R pod]
   ◯                                               ◯
   │                                               │
   ●━━━━━━━━━━~~~~~~~~~~~~~~━━━━━━━━━━●
    ↑ 시작: L 스템 끝에서          ↑ 끝: R 스템 끝으로 흡수
    
  시간:  0ms       600ms       1200ms       1800ms
  크기:  작게 출발 → 중간에 팽창 → 끝에서 수렴
  투명도: 0 → 1.0 → 0.8 → 0
```

### 디테일 6가지

1. **파형 형태**
   - 중심선 + 위아래 사인파 모양 (오디오 웨이브폼 느낌)
   - 진폭은 메시지 길이에 비례 (짧은 메시지 = 낮은 파동, 긴 메시지 = 높은 파동)
   - 점(particle) 5–7개가 파동 곡선을 따라 흐름

2. **이동 경로**
   - L pod 스템 끝에서 출발
   - **살짝 아래로 늘어진 포물선** 궤도 (중력 있는 듯)
   - 화면 중앙에서 최대 진폭
   - R pod 스템 끝으로 빨려 들어감
   - easeInOutCubic 타이밍

3. **색상**
   - 방 accent 색 (민트/골드/블루) 그라디언트
   - L pod 쪽은 투명 10%, 중간은 80%, R pod 쪽은 다시 투명
   - Glow 필터 약하게 (blur 4pt)

4. **음성 vs 텍스트 구분**
   - 텍스트 메시지: **점선 파동** (토막난 대시)
   - 음성 메시지(v1.1+): **연속 파동** + 파동 위에 실제 파형 그래프 겹침

5. **도착 연출**
   - 파동이 R pod에 닿는 순간 **pod이 가볍게 흔들림** (0.5° 기울어졌다 복귀)
   - 동시에 R pod에 메시지 텍스트가 fade-in
   - 햅틱 light impact 동기화

6. **역방향 (`A05: voice_wave_R_to_L`)**
   - 정확히 미러링
   - 방에서 L/R 슬롯이 교대로 활성화될 때 이 두 애니메이션이 번갈아 재생
   - "대화가 진짜 오가는" 감각

### 타임라인 (Animated video Skill로 제작 권장)

```
 0ms   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 1800ms
 │
 │  L pod 스템 끝 발광 + 파동 점 1개 생성
 │    ↓
 200ms  파동 점 2,3개 추가 생성, 오른쪽으로 가속
 │    ↓
 600ms  화면 중앙 도달, 진폭 최대, 모든 점 가시
 │    ↓

 │    ↓

 │    ↓
 1700ms R pod 접촉 → pod 살짝 기울어짐 + 발광
 │    ↓
 1800ms 파동 소멸, R pod에 메시지 텍스트 fade-in (200ms 겹침)
```

### 스테레오 오디오 동기화 (코드 힌트)

```swift
// 애니메이션 시작과 동시에 팬 값을 -1 → +1로 보간
AVAudioEngine mixer pan: -1.0 → +1.0 over 1.8s
// 메시지 도착 알림음도 같은 타이밍에 L→R 이동
// 에어팟 착용 시 실제 귀로 왼쪽→오른쪽 소리 이동 감지됨
```

### 방향 규칙
- 방 메시지 순서와 상관없이 **L/R 슬롯 교대로 배정**
- 직전 메시지가 L에 있었으면, 새 메시지 파동은 **R→L 방향**이 아니라 **L→R** (새 메시지는 빈 슬롯 쪽으로)
- 혼란 방지: **항상 "빈 슬롯으로 향하는" 방향**

### 빈도/주기
- 메시지 표시 간격은 2초 (큐잉 기본값) → 파동 1.8초 + 쉼 0.2초
- 트래픽 많을 땐 파동 겹치지 않게 **한 번에 하나만** 재생 (큐 우선)

### 에러/저사양 대응
- Lottie 재생 드롭 감지되면 **단순 스테이트릭 선형 이동**으로 폴백
- `UIAccessibility.isReduceMotionEnabled == true` 시: **페이드만 남김, 파동 생략**

## C13. **디자인 시스템 "지리게" — 앱 전체를 관통하는 시그니처 모션 언어**

> 요청: "디자인 시스템 애니메이션 지리게"
> 해석: 정적 토큰만으로는 부족. **앱 곳곳에 관통하는 모션 문법**이 있어야 "와 이 앱 뭐야" 반응 나옴.

### 모션 철학 3대 원칙

#### 원칙 1. **"숨 쉰다"** (Everything breathes)
모든 idle 요소는 **아주 미세하게 호흡**한다.
- pod → 2초 주기 scale 0.96↔1.0
- 접속자 수 칩 → 점 하나가 깜빡임
- 닉네임 칩 → 3초 주기 glow 미묘하게 변동
- 빈 상태 텍스트 → opacity 0.5↔0.8 호흡
→ **앱이 "살아있다"는 감각.** Discord/Clubhouse처럼.

#### 원칙 2. **"소리가 보인다"** (Sound is visible)
모든 인터랙션에는 **파동** 또는 **링** 피드백이 있다.
- 탭 → 터치 지점에서 원형 링 퍼져나감 (100ms)
- 메시지 전송 → 입력창 전체가 파동 한 번 (left→right shimmer)
- 리액션 → 파티클 + 미세 사운드 웨이브 그림자
- 방 전환 → 새 방의 accent 색이 파동으로 밀려옴
→ **앱 곳곳이 "청각적"인 비주얼**을 가짐.

#### 원칙 3. **"사라질 때 우아하게"** (Vanishing with grace)
휘발성이 핵심이니까, 사라지는 모든 순간이 **앱의 미학**이다.
- 메시지 사라짐 → opacity + 살짝 위로 + 약간 blur (절대 툭 끊지 않음)
- 모달 닫힘 → 아래로 밀려나며 뒤쪽 뷰 scale 0.98→1.0
- 토스트 → 300ms 페이드 + 2pt 상승
- 키보드 내려감 → 스프링 댐핑 강하게 (튕김 없이)
→ **모든 exit이 "연기가 피어오르듯"**.

### 시그니처 모션 6종 (디자인 시스템 필수)

| ID | 이름 | 적용 |
|---|---|---|
| `M01` | **Breath** | idle 요소 전반 (pod, 칩) |
| `M02` | **Ripple** | 모든 탭 피드백 |
| `M03` | **Wave L↔R** | 메시지 이동 (C12 참조) |
| `M04` | **Puff Vanish** | 메시지 사라짐 |
| `M05` | **Glass Shift** | 글래스 표면이 빛 각도에 따라 미세 변화 |
| `M06` | **Accent Pulse** | 방 전환·강조 시 accent 색 파동 |

### 타이밍 시스템 (표준화)

```
motion/instant    100ms   cubic-bezier(0.4, 0, 0.2, 1)    탭 피드백
motion/fast       180ms   cubic-bezier(0.2, 0.9, 0.3, 1)  리액션 버스트
motion/base       260ms   cubic-bezier(0.33, 1, 0.68, 1)  UI 전환
motion/slow       450ms   cubic-bezier(0.5, 0, 0.2, 1)    방 전환
motion/flow       1800ms  cubic-bezier(0.4, 0, 0.2, 1)    L↔R 파동
motion/breathe    2000ms  ease-in-out 무한 루프           idle 호흡
```

### 모션 접근성
- `reduce motion` 시:
  - M01 Breath → 정적
  - M03 Wave → 페이드 크로스오버로 대체
  - M05 Glass Shift → 고정
  - M04 Puff → 단순 fade
- 그 외(M02 Ripple, M06 Accent Pulse)는 유지

### 음향 동기화 (v1.1 라디오 모드 대비)
- 모든 주요 모션은 **대응 사운드 이벤트**를 가짐
- pod receive → 은은한 "tap" (150Hz 톤, 50ms)
- wave L→R → 스테레오 팬 이동 화이트노이즈 (1.8s)
- vanish → 약한 "whoosh"

   - 본체와 같은 재질
   - 끝에 **얇은 크롬 링** (`#D0D0D5`) 디테일 포인트

- **키 라이트**: 좌측 상단 45°에서 내려옴 (소프트)
- **림 라이트**: 우측 하단에서 약하게 — pod 실루엣 강조
- **앰비언트**: 다크 배경의 네온 글로우가 pod 하단에 살짝 반사


### 반사 (Reflection)
- pod 상단 곡면에 **이동 가능한 하이라이트** (Phong 스타일)

### 크기 & 비율
- **실제 AirPods 비율**: 본체 : 스템 = 약 1 : 1.2
- 화면에서 pod 전체 높이 = 화면 세로의 약 35–40%
- 본체(원형 부분) : 스템(막대) 비율 정확히 지킬 것
- 각도: 살짝 살짝 비스듬 (수직 일자 X). L은 좌하단으로, R은 우하단으로 5° 정도 기울임

### 상태별 변화
- **idle**: 기본 조명, 은은한 글래스 느낌
- **active (메시지 표시 중)**: accent glow 켜짐, 크롬 링에 색 반사
- **reacting**: 하이라이트가 순간 강해짐 (플래시)
- **disappearing**: 상단 하이라이트가 빠르게 옅어짐

# ⑤ USER FLOWS

## Flow 1. 최초 진입 (Onboarding)

```
앱 실행
  └─ S01 스플래시 (2초)
      └─ S02 온보딩 1/3  [다음]
          └─ S03 온보딩 2/3  [다음]
              └─ S04 온보딩 3/3  [알림 허용] or [나중에]
                  └─ 자동 닉네임 생성
                      └─ S06 메인 (기본: 일상방)
```

**포인트**: 온보딩은 3장 이내. 회원가입 X.

---

## Flow 2. 메시지 보내기 & 받기 (Core Loop)

```
S06 메인 (일상방, 메시지 활발)
  ├─ 들어오면 R pod에 "퇴근하고싶다" 들어와 있음
  ├─ 2초 뒤 L pod에 "나도 ㅠㅠ" 새로 뜸 (기존 R은 유지)
  ├─ 2초 뒤 R pod 교체: "오늘 저녁 뭐 먹지"
  └─ 사용자가 입력창 탭
      └─ S08 입력창 올라옴, 키보드 ON
          └─ "치킨" 입력 후 [→] 전송
              └─ S09 내 메시지 하단 에코 3초
                  └─ 3초 후 에코 사라짐, 메인 유지
                  └─ (서버에서 내 메시지도 L/R 큐에 합류해서 돌아옴)
```
