# Sauna · Personas

> 한국 커뮤니티 헤비유저("커뮤충") 5명을 합성하고, 각자가 Sauna에서 원하는 것과 그것이 Sauna 설계 결정에 어떻게 매핑되는지 정리.
>
> 작성일: 2026-04-27
> 합성 기반: NVIDIA Nemotron-Personas-Korea 데이터셋 스키마 + 한국 커뮤니티 서브컬처 지식
> 보조 컨텍스트: `docs/competitive-analysis.md` (경쟁사 사망 함정)

## 1. 한 줄 요약

Sauna의 핵심 사용자는 **"갈 곳 없는 익명 한국 직장인/취준생"** 이다. 합성한 5명 모두가 공통으로 원하는 것은 4가지 — (1) **흔적 0**, (2) **인증 없음**, (3) **1:1 강요 없음**, (4) **톤이 더럽지 않을 것**. 이 네 기둥이 Sauna의 핵심 가치 제안과 정확히 겹친다.

데이터셋 자체는 인구 분포 일반(노년층 포함)이라 "커뮤충" 서브컬처가 명시적으로 들어있지 않다. 아래 5명은 데이터셋의 스키마(나이/성별/시군구/직업/persona/관심사)를 차용해 한국 커뮤니티 문화 지식으로 합성한 것. 다음 검증 단계는 §6 참고.

## 2. 5 페르소나

### P1. 김민호 — "회사 욕 끊을 곳이 없는 자"

| | |
| :--- | :--- |
| 나이/성별 | 31 / 남 |
| 거주지 | 서울 강서구 (회사 판교) |
| 직업 | 중견 IT 백엔드 개발자 5년차 |
| 가구 | 미혼 1인 |
| 주 커뮤니티 | **블라인드**(메인) · 디시 프갤 · 카톡 IT 오픈채팅 |

**행동 패턴**
점심·퇴근길·자기 전 블라인드 끝없이 새로고침. 회사 라운지는 보기만, 산업 라운지에 가끔 던지는데 "이 회사 사람이 누군지" 추정당할까 늘 신경 씀. 카톡 IT 오픈채팅은 변태/홍보 많아 정 떨어짐.

**원하는 것**
- 회사 인증 없이 회사 욕할 곳
- 옆 팀원이 알아챌 가능성 0
- 같은 직장인 페이소스 공감 (정착은 싫음)

**Sauna에서**
퇴근 직후 **일상방** 입탕. 휘발성 = "내가 한 말이 캡쳐돼서 회사로 돌아올 가능성 0"이 결정타. 닉네임 매일 리셋 = 어제의 발화에 묶이지 않음.

**이 사용자가 만들 위험**
회사 실명 비방 도배. → 회사명 필터로 막으면 본질 죽음. 도배 rate-limit으로만 처리.

### P2. 박지윤 — "장 끝나면 부끄러운 단타충"

| | |
| :--- | :--- |
| 나이/성별 | 27 / 여 |
| 거주지 | 부산 해운대구 |
| 직업 | 중소기업 마케팅 4년차 |
| 가구 | 미혼 / 본가 거주 |
| 주 커뮤니티 | **네이버 종목토론실** · 디시 주갤 · 카톡 종목 오픈채팅 · 텔레그램 리딩방 |

**행동 패턴**
9시 30분에 심장 뜀. VI 뜨면 종토방 폭발하는 거 보러 들어감. 손실 난 날엔 새벽 3시까지 푸념 글 → 다음날 글 지움. 주식 얘기 같이 할 친구 없음 (다 직장인). 종토방은 빠른데 비아냥이 본문보다 많음.

**원하는 것**
- VI 떴을 때 같은 종목 사람들과 실시간 환희/절망 공유
- **다음날 흔적 0** (어제 손절 푸념을 오늘의 내가 안 봐도 됨)
- 리딩방 홍보 없는 곳

**Sauna에서**
**주식방** packed 모드. 자정 리셋 = 어젯밤 손절 절규가 0이 되는 카타르시스. 사진/링크 X = 리딩방 홍보 차단.

**이 사용자가 만들 위험**
종목 추천 도배, 펌프 앤 덤프. → "특정 종목명+추천/매수" 패턴 rate-limit. 단 *느슨하게* — 막으면 본질 죽음.

### P3. 이서연 — "어제와 같은 푸념을 하고 싶은 N수 취준생"

| | |
| :--- | :--- |
| 나이/성별 | 25 / 여 |
| 거주지 | 경기 성남시 분당구 (본가) |
| 직업 | 무직 (공기업 NCS 1년 7개월차) |
| 가구 | 미혼 / 부모와 |
| 주 커뮤니티 | **디시 취갤** · 인스티즈 취업판 · 트위터 비공계 · 잡플래닛 |

**행동 패턴**
아침에 도서관 자리 잡고 인강 틀어놓음. 집중 안 되면 취갤 새로고침. 공기업 발표날엔 새벽 4시까지 깨있음. "또 떨어졌어" 글을 같은 커뮤에 반복하면 "이번이 몇 번째냐"는 댓글 트라우마. 트위터 비공계는 친구들이 알아챌까 봐 또 부담.

**원하는 것**
- **매일 같은 푸념을 새 사람한테 처음인 양 할 수 있는 곳**
- 들어주는 사람 (조언 X, 그냥 들어줌)
- 어제의 푸념과 오늘의 푸념이 끊어진 곳

**Sauna에서**
**취준방** 새벽 lonely 모드. 매일 자정 닉네임 리셋 = "어제 그 사람"이라는 인식 자체가 불가능 = 같은 푸념을 매일 새롭게 가능. 이게 *치료적*임.

**이 사용자가 만들 위험**
자해/극단 표현. → 키워드 감지 시 안전 자원(자살예방상담전화 1393) 살짝 띄우는 ambient 처리 필요.

### P4. 정현우 — "백색소음으로서의 사람 존재감이 필요한 자"

| | |
| :--- | :--- |
| 나이/성별 | 34 / 남 |
| 거주지 | 인천 연수구 송도 |
| 직업 | 외국계 컨설팅 매니저 |
| 가구 | 미혼 1인 |
| 주 커뮤니티 | **더쿠**(아이돌) · 오늘의유머 · 카톡 오픈채팅 새벽 토크방 · 트위터 |

**행동 패턴**
새벽 1-4시 자기 직전 의식. 1:1 톡은 부담스럽고 (대답해야 함), 게임은 머리 쓰임, 유튜브는 정보 과잉. 그냥 *누군가 있는 공간*에 있고 싶음. 옛날엔 카톡 오픈채팅 새벽방에서 한마디도 안 하고 보기만 했는데 거기도 1:1 DM 들어옴.

**원하는 것**
- 말 안 해도 되는 공간
- 누군가 있다는 느낌만
- 1:1 강요 0

**Sauna에서**
**일상방** 새벽 lonely 모드. 가끔 말풍선 하나 떠올랐다 사라짐. 그게 끝. 1:1 DM 구조적으로 없음 = 평화. **이 사람한텐 Sauna가 거의 완벽한 답.**

**이 사용자가 만들 위험**
너무 적막하면 이탈. → lonely 모드에도 ambient 시그널 필요 ("오늘 강남구 훅훅" 류).

### P5. 한수진 — "어디에도 정착 못한 커뮤니티 난민"

| | |
| :--- | :--- |
| 나이/성별 | 29 / 여 |
| 거주지 | 대구 수성구 |
| 직업 | 프리랜서 일러스트레이터 |
| 가구 | 미혼 1인 |
| 주 커뮤니티 | (과거) **더쿠** → 졸업 · 카톡 오픈채팅 → 변태/홍보 짜증 · 클리앙 → 톤 부담 · 트위터 → 정체 노출 위험 |

**행동 패턴**
대학 때 더쿠 헤비유저였는데 "졸업"하고 갈 곳 없음. 에브리타임은 학교 인증 막힘. 블라인드는 프리랜서라 회사 인증 안 됨. 카톡 오픈채팅은 첫 메시지가 "여자세요?" 류라 닫음. 트위터는 그림 계정과 분리 어려움. **3년째 진짜 익명 라운지를 찾아 떠도는 중.**

**원하는 것**
- 인증 없음
- 정착 압박 없음
- 첫 진입 시 톤이 더럽지 않을 것
- 1:1 DM 차단되어 있을 것

**Sauna에서**
3방 모두 짧게 들렀다 나감. 매일 새 닉네임 = "여기서도 정착해야 하나" 압박 없음. 사진/DM 없음 = 변태 차단. **이 페르소나가 Sauna의 가장 까다로운 평가자 — 첫 인상에서 톤 어긋나면 즉시 이탈하고 안 돌아옴.**

**이 사용자가 만들 위험**
가장 까탈스러운 사용자 = 가장 가치 있는 사용자. UX/타이포/모션 한 군데라도 어색하면 잃음.

## 3. 공통 욕구 → Sauna 4대 기둥

| 기둥 | 누가 가장 원함 | Sauna 설계 결정 | 상태 |
|---|---|---|---|
| 흔적 0 (휘발성) | P1, P2, P3 | 메시지 영속 부재 + 자정 닉네임 리셋 | ✓ 채택 (PRD §1, §6) |
| 인증 없음 | P5 | 회원가입 X (OAuth도 X) | ✓ 채택 (PRD §8) |
| 1:1 강요 X | P4, P5 | DM 구조적 부재 | ✓ 채택 (PRD §8) |
| 톤 일관성 | P5 (가장 강함), P4 | 사진/링크 X + 이모지 X + 첫진입 임팩트 | ✓ 부분 (모션/타이포 디테일 미정) |

## 4. 공통 위험 → 대응

| 위험 | 출처 페르소나 | 대응 |
|---|---|---|
| 도배/광고 | P1(회사욕), P2(종목추천) | 서버 rate-limit. 키워드 차단 X (본질 죽음) |
| 안전 위기 표현 | P3 | 키워드 감지 시 ambient 안전 자원 노출 (자살예방 1393 등) |
| 적막으로 인한 이탈 | P4 | lonely 모드에 ambient 시그널 ("오늘 강남구 훅훅") |
| UX 첫인상 | P5 | DesignSystem/모션을 "낭비라 느낄 만큼" 다듬기 |

## 5. 페르소나가 알려주는 룸 별 특성

| 방 | 핵심 페르소나 | 시간대 피크 | 톤 |
|---|---|---|---|
| **일상** | P1, P4, P5 | 점심 / 퇴근 / 새벽 | 푸념 + 백색소음 |
| **주식** | P2 | 9-15시 (장중), VI 시 폭증 | 도파민 + 절규 |
| **취준** | P3 | 새벽 + 발표일 폭증 | 자조 + 위로 |

→ 이는 `docs/PRD.md` §4.3 (Room 4 화면) 의 `daily/medium`, `stock/packed`, `job/lonely` 디자인 변형이 정확히 페르소나 트래픽 패턴과 일치함을 보여줌. 디자인 정본은 이미 페르소나 정합성 있음.

## 6. 다음 검증 단계 (선택)

순서대로:

1. **데이터 검증**: Nemotron-Personas-Korea에서 `age 25-35` + `수도권/광역시` + `IT/마케팅/무직` 필터로 1만 명 추출 → 취미·관심사 군집 분석. 본 페르소나가 실제 분포에 부합하는지 확인.
2. **인터뷰**: 각 페르소나에 대응하는 실제 사용자 5명 리쿠르팅 → 30분 인터뷰 (paper prototype 또는 sauna-app.html 데모).
3. **클로즈드 베타**: TestFlight 100명, 페르소나당 20명. KPI: D1 retention, 첫 방 진입까지 시간, 첫 발화까지 시간.
