# Sauna · Product Requirements Document

> Source of truth: `design-handoff/sauna-app.html`
> 작성일: 2026-04-24

## 1. 제품 정체성

**"원목 사우나실 안에서 익명으로 땀 흘리듯 말을 뱉는 앱."**

- 이름은 매일 자정 새로 배정
- 말은 증기처럼 올라오다 사라짐
- 세션 기록 X (메시지 히스토리 원천 부재)
- 시간 제한 X · 언제든지 나갈 수 있음

## 2. 타겟 사용자

- 한국 20–35 직장인 · 취준생 · 대학생
- iOS 17+ (Android 후속)
- 한국 한정 MVP

## 3. 핵심 가치

| | 내용 |
|---|---|
| Why | 회원가입 없이 즉시, 부담 없이 수다 |

| What | 일상 · 주식 · 취준 (+ 시즌 방) |

## 5. 절대 피할 것

- 말풍선 채팅 리스트 (카톡 스타일) — 증기 말풍선 본질과 충돌
- 프로필 사진 / 아바타 (커스텀 `AnonAvatar`만 사용)
- 파스텔 · 뽀얀 톤
- 무거운 일러스트
- 이모지 (앱 전체에서 금지)

## 6. 기능 범위 (v1 MVP)

### MUST
- 익명 닉네임 (자정마다 재발급)
- 방 3개 (일상/주식/취준) 글로벌 단일
- 증기 말풍선 실시간 표시 & 휘발
- 언제든 ← 나가기
- 키보드 입력 & 전송
- 프로필 · 설정 · 알림 프리뷰
- 커스텀 SVG 아이콘 세트 (24종)

### SHOULD (이후 스프린트)
- 방 진입 트랜지션 (문 열림 · 증기 확산)
- 증기 입력 시 "말이 증기로 변하는" 모션
- 시즌 방 추가 플로우 (admin)
- 접속자 수 팝오버
- Empty state · 에러/연결 끊김

### COULD
- NPC 자동 발화 (적막할 때)
- 차단 · 신고 · 뮤트
- 폰트 크기 · 모션 설정

## 7. 후원/네임드 기획 메모 (v2+)

- 개발자에게 후원 → 네임드 뱃지 선택권
- 현재 단계는 **기획만**, v1 구현에는 포함 X

## 8. 제약/비-목표

- 회원가입 X (OAuth도 안 함)
- 메시지 영속 저장 X
- 1:1 DM X
- 파일/이미지 전송 X
- 읽음/타이핑 표시 X

## 9. 리스크

- **도배/혐오 발화**: 휘발성이라 모더레이션 어려움. 클라이언트-사이드 필터 + 서버 신고 필요
- **실시간 부하**: 글로벌 단일 방이라 피크 시 수천 명 동시. Pub/Sub 구조 필수
- **iOS 알림 권한**: 온보딩 초반에 요청하면 거부율 높음. 의미 설명 후 점진 요청
